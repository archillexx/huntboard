# Huntboard — frontend

The React app for [huntboard.dev](https://huntboard.dev) (React, React Router, Tailwind CSS, Vite).
See the [main README](../README.md) for what Huntboard is, how it's built and how to run it.

```sh
npm ci
npm run dev      # http://localhost:5173 (expects the API at VITE_API_URL, see .env.development)
npm run build    # production build into dist/
```
